# 0004 — Provenance des dimensions

Date : 26/10/2026 · Statut : accepté

**Décision.** Provenances : catalogue, fiche produit (web), mesurée, estimée, inconnue. Une dimension estimée non confirmée ou inconnue bloque l'optimisation. Toute saisie manuelle passe en « mesurée ». Une note de source (`dimNote`) accompagne la valeur et s'importe depuis le CSV (colonne « Source des dimensions »).

**Conséquences.** Respect du PRD §4.4 et §18 (« les dimensions ne sont pas inventées »). Le test lessive montre que les fiches web sont rares : prévoir la mesure en magasin.
